# AI RPG Chat

A single-player fantasy RPG played almost entirely through chat with an AI game master, with a god console for shaping the world and its characters.

## Language

**World**:
The reusable template of a game: lore, rules, locations, factions, and characters. One World can run many Campaigns.
_Avoid_: Setting, universe, scenario

**Campaign**:
One playthrough of a World, holding its own current state and history.
_Avoid_: Save, session, run, game

**Game Master**:
The AI that narrates the Campaign, voices NPCs, and proposes state changes that the game validates.
_Avoid_: DM, narrator, bot

**Player Character**:
The character the player controls in a Campaign. Its stats can be edited at any time.
_Avoid_: Hero, avatar, main character

**NPC**:
A character controlled by the Game Master, with its own profile, goals, memory, and relationship to the Player Character.
_Avoid_: Bot, mob

**Character Profile**:
The descriptive record of a character: personality, goals, secrets, relationships, stats, inventory, and portrait.
_Avoid_: Character sheet, bio

**Portrait**:
A character's profile picture, either uploaded by the user or generated by AI from keywords.
_Avoid_: Avatar, icon

**God Console**:
The pop-up admin interface for editing the World, Characters, and live Campaign state.
_Avoid_: Admin panel, dashboard

**Draft**:
An AI-generated proposal made from keywords that the user reviews, edits, and approves before it is saved.
_Avoid_: Suggestion, preview

**Snapshot**:
A saved point in a Campaign's history that the Campaign can be rewound to.
_Avoid_: Checkpoint, backup

**Offscreen Tick**:
A light update of goal-driven NPC activity that runs when in-game time jumps, recorded as World events.
_Avoid_: Simulation, background turn

**God's Blessing**:
An in-world event, narrated by the Game Master, that represents a God Console edit to live Campaign state (a Curse when the edit is negative). Edits can also be made silently.
_Avoid_: Override, cheat, admin edit

**Journal**:
The player's read-only record of quests, people met, places visited, and past events, limited to what the Player Character has learned.
_Avoid_: Log, codex

**Branch**:
A timeline archived when a Campaign is rewound to a Snapshot, which can be revisited later.
_Avoid_: Fork, save slot

**Recall**:
The Game Master's search of the full Campaign history for a detail from long ago.
_Avoid_: Lookup, memory query

**NPC Memory**:
What an NPC has witnessed or been told, plus its relationship score toward the Player Character.
_Avoid_: Knowledge base, history
